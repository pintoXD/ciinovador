# Multiplicador em Ponto Flutuante com técnicas DFT

Neste projeto foi utilizado o multiplicador de ponto flutuante e está organizado como se segue: 

* `backend:` Conteúdo relativo a síntese lógica e física
  * `layout:` Códigos para síntese física;
    * `deliverables:` Entregáveis pós-síntese
    * `reports:` Relatórios gerados pós-síntese (Ex.: Power, Area, Timming);
    * `scripts:` Códigos de automatização de síntese;
    * `work:` Arquivos temporários gerados pelas ferramentas;
  * `synthesis:` Códigos para síntese lógica 
    * `deliverables:` Entregáveis pós-síntese
    * `reports:` Relatórios gerados pós-síntese (Ex.: Power, Area, Timming);
    * `scripts:` Códigos de automatização de síntese;
    * `work:` Arquivos temporários gerados pelas ferramentas;
* `frontend:` Conteúdo relativo a implementação do design do módulo multiplicador
